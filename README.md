A clean, modern Monthly Budget Planning App built using React.js and Tailwind CSS.
This app allows users to set a monthly budget, add expenses, track spending, and view remaining balance — all organized month‑wise using a built‑in calendar selector.

-Features

✅ Monthly Budget Tracking

Select any month using a calendar input

Set a unique budget for each month

Automatically loads saved data when switching months

✅ Expense Management

Add expenses with name + amount

View all expenses for the selected month

Delete expenses instantly

✅ Smart Calculations

Total Budget

Total Spent

Remaining Balance

Auto‑updates in real time

✅ Modern UI

Tailwind CSS styling

Soft shadows, rounded cards, clean layout

Wallet icon in navbar (Heroicons)

Fully responsive

Clean UI with smooth layout and spacing

✅ How It Works

- User selects a month

- App loads budget + expenses for that month

- User sets a budget

- User adds expenses

- App calculates:

- Total spent

- Remaining balance

- Data is stored in React state (month‑wise)

- Switching months shows different data.

⭐ Future Enhancements

LocalStorage support

Expense categories

Dark mode

Export monthly report as PDF

Search & filter expenses.

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
